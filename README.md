# सेक्स प्लेलिस्ट — Sensual Lounge & Rhythm Player

A minimalist, aesthetic web music player featuring 150 local master sensual and rhythm tracks, live dynamic clock, and authentic animated film grain visuals.

## ✨ Features
- **150 Master Songs (Full Length):** Instant local playback of English & Hindi tracks with zero cutoffs or buffering.
- **Synchronized Vinyl Cover Artwork:** The spinning vinyl disc displays the official high-resolution album artwork for each song.
- **Dynamic Sequence Shuffling:** Automatically randomizes the entire playlist queue on every fresh session.
- **Language Filter Switcher:** Seamlessly filter between `All` (Mixed), `No Hindi` (English Only), and `Only Hindi`.
- **Atmospheric Visuals:** High-resolution impressionist backdrop with authentic 35mm animated cinema grain that reacts to music playback.
- **Live Dynamic Clock:** Real-time ticking system clock with seconds in the top-left.
- **Controls & Accessibility:** Keyboard shortcuts (`Space` to play/pause, `Arrow Right` / `Arrow Left` to skip, `F` for Fullscreen).

## 🚀 Live Deployment
To deploy live with GitHub Pages:
1. Go to your GitHub Repository **Settings** > **Pages**.
2. Under **Branch**, select `main` (or `master`) and folder `/ (root)`.
3. Click **Save** — your site will be live instantly!

## 💻 Local Development
```bash
npx http-server -p 8080 -c-1
```
Visit `http://localhost:8080` in your browser.
